  `8b1fa94aaf9f1719d3c61793bd960344531335270ab88b82c908ca2184b094f9`.
- Восстановлены SHA-256-проверенные patch и Rust helpers из архива этого bake. Пакетная запись v4 и

  переходы состояния, штрафы за пропуски и финализация. Используется штатный первый diff-слой 512
  слотов (`9,13,16,18,21`).
